# Talos v0.6.5 Beta — Release Notes

**Status:** Public beta  
**Tag:** `v0.6.5-beta`  
**Platforms:** Android APK, Web (EAS Hosting)

## Highlights

Talos is a unified client for discovering, reading, watching, organizing, and downloading supported manga, novels, and anime.

This beta includes:

- Multi-provider search and discovery
- Manga / webtoon reader with zoom and gestures
- Novel reader with continuous and chapter modes
- Anime playback with subtitle support where available
- Bookmarks, downloads, library, and progress
- Scraper Backend providers via the Talos Render service
- Optional in-app update notifications (GitHub Releases only)

## Install (Android)

1. Download the APK from this GitHub Release
2. Allow install from unknown sources if prompted
3. Open Talos and browse Sources to enable providers

Talos does **not** auto-install updates. When notified, Download opens this Releases page.

## Known limitations

- Upstream providers can break or block without notice
- Some scraper sources may be limited from the cloud backend
- Render free tier may sleep; first request can be slow
- This is a beta — expect rough edges
